Cornercase remote puts the coding agents you run in cornercase on your computer in your pocket. Follow them, answer them and start new work from your iPhone or iPad, while they keep running on the computer.

It works with the cornercase app on your computer (Linux or macOS): you need cornercase 0.13.78 or later, and a phone that can reach that computer, on the same network or with both on your Tailscale network.

SEE EVERY AGENT ON ONE BOARD
Each agent of your projects shows with its status and for how long it has been in it. The ones that need you come first, and the agents they started fold under them. The board updates live.

TALK TO AN AGENT
Tap an agent to read its conversation and its last message, see what it is doing right now, and answer it. When it asks a question, its options show as buttons. A row of keys sends Enter, Tab, the arrows, a digit, Esc or Ctrl-C. Attach images from your photos: they are shrunk on the phone, without their location, and reach the agent with your next message.

OPEN THE LIVE TERMINAL
See the agent's terminal as it runs, fitted to your screen's width, and type into it with the keys a terminal needs.

START NEW WORK
Start an agent with a prompt, in a workspace that is already open or in a new worktree, with the agent, account and model you pick. Or start an agent or a flow on an issue from any tracker cornercase is connected to.

CHECK THE CHANGES AND THE FILES
See which files a workspace changed, read each diff and mark it viewed, as cornercase's changes panel does. Browse the workspace's files, read a file or a picture, and search them by name.

CLOSE AN AGENT
Swipe a row left, or tap Close agent on its screen. The app shows what will close and asks before closing it.

PAIR WITH YOUR COMPUTER
In cornercase on your computer, open Settings > Remote > Phone app, then scan its QR code from the app's Machines screen, or paste the code. Add one machine per computer, give it a name and switch between them; the app opens the last one you used.

TRY IT WITHOUT A MACHINE
Tap Try a demo on the first screen to open a demo machine simulated on the phone, marked DEMO, with sample agents to read, message, answer, start and close. It uses no network and saves nothing. Tap Leave demo on the connection bar to go back.

PRIVATE BY DESIGN
The app has no account and collects nothing. It talks only to the machines you pair it with.
